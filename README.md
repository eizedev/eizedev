## <img src="https://raw.githubusercontent.com/eizedev/brand/main/pivotkit/out/icon.svg" alt="" height="28" align="top"> [pivotkit](https://github.com/eizedev/pivotkit)

**Excel's PivotTable for web apps and the command line.** People load their data, build the report by dragging fields and take it to Excel. The same report renders again in CI, behind a REST service or for an AI client.

- **Bring your own file.** CSV, JSON or Excel dropped onto the report, with a preview and a type per column. Nothing is uploaded.
- **Excel with the layout kept,** plus the rows behind every number as CSV or JSON.
- **Views are safe JSON** with a published schema. A view cannot run code, and the CLI checks it in CI.
- **One report, many places:** React, a web component, Node, a command line, a REST service with a container image, and an MCP server that never hands the model the rows.

[Try the live demo](https://pivotkit.eize.dev/playground/) · [Documentation](https://pivotkit.eize.dev/) · [Compared with others](https://pivotkit.eize.dev/compare/) · [![npm](https://img.shields.io/npm/v/pivotkit-react?style=flat-square&labelColor=1f2430&color=61afef&label=npm)](https://www.npmjs.com/package/pivotkit-react)
